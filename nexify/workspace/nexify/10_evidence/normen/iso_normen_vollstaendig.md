## 1. Qualitätsmanagement

### ISO 9001:2015 (2026 in Revision)
| Feld | Wert |
|------|------|
| **Titel** | Qualitätsmanagementsysteme – Anforderungen |
| **Aktuelle Version** | ISO 9001:2015 |
| **Revision** | ISO 9001:2026 (tritt voraussichtlich September 2026 in Kraft) |
| **Beschreibung** | Internationale Basisnorm für Qualitätsmanagement. Anforderungen an QM-Systeme – prozessorientierter Ansatz, kontinuierliche Verbesserung, Kundenzufriedenheit. Für AI-Agentur essentiell als Grundlage für Zertifizierung und Kundenvertrauen. |
| **Quelle** | https://www.iso.org/standard/62085.html |
| **Doku-Link** | https://www.secjur.com/blog/iso-9001 |

### ISO 13485:2016
| Feld | Wert |
|------|------|
| **Titel** | Medizinprodukte – Qualitätsmanagementsysteme – Anforderungen für regulatorische Zwecke |
| **Aktuelle Version** | ISO 13485:2016 |
| **Beschreibung** | QM-Systeme für Medizinprodukte-Hersteller. Relevant falls AI-Agentur Software als Medizinprodukt (SaMD / MDR) entwickelt. Strengere Anforderungen als ISO 9001. |
| **Quelle** | https://www.iso.org/standard/59752.html |

### ISO/IEC 15504 (SPICE)
| Feld | Wert |
|------|------|
| **Titel** | Informationstechnik – Prozessbewertung (SPICE – Software Process Improvement and Capability Determination) |
| **Aktuelle Version** | ISO/IEC 15504 (mehrere Teile, ersetzt durch ISO/IEC 33000-Reihe) |
| **Beschreibung** | Rahmenwerk zur Bewertung der Prozessfähigkeit in der Softwareentwicklung. Definiert Reifegradmodelle (Capability Levels 0–5). Im Automotive-Bereich oft durch Automotive SPICE ersetzt. |
| **Quelle** | https://en.wikipedia.org/wiki/ISO/IEC_15504 |

### ISO/IEC 25000-Reihe (SQuaRE)
| Feld | Wert |
|------|------|
| **Titel** | Systems and software Quality Requirements and Evaluation (SQuaRE) |
| **Aktuelle Version** | ISO/IEC 25000:2014 (Familie, viele Einzelnormen) |
| **Beschreibung** | Rahmenwerk für Softwarequalität. Enthält Qualitätsmodelle (25010:2011 – Qualitätsmerkmale), Messung (25020/25030), Evaluierung (25040/25045). Definiert: funktionale Eignung, Zuverlässigkeit, Benutzbarkeit, Effizienz, Wartbarkeit, Portabilität, Sicherheit, Kompatibilität. |
| **Quelle** | https://iso25000.com/index.php/en/iso-25000-standards |

## Zusammenfassung: Relevanz-Matrix für AI-Agentur

| Priorität | Norm(en) | Begründung |
|-----------|----------|------------|
| 🏆 **Kritisch** | ISO 9001, ISO/IEC 27001, ISO/IEC 42001 | Zertifizierbare Managementsysteme: QM, Security, KI – Basis für Kundenvertrauen |
| ⭐ **Hoch** | ISO/IEC 27701, ISO/IEC 27002, ISO 31000, ISO 22301 | Datenschutz, Security-Umsetzung, Risikomanagement, Business Continuity |
| 🔶 **Mittel** | ISO/IEC 25000, ISO/IEC 12207, ISO/IEC 20000, ISO 21500 | Softwarequalität, Entwicklungsprozesse, IT-Service, Projektmanagement |
| 🔹 **Niedrig** | ISO 26262, ISO 13485, ISO 15504 | Nur bei spezifischen Branchen (Automotive, Medizin) |
