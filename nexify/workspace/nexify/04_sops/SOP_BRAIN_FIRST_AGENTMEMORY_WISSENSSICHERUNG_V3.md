# SOP — Brain-first, agentmemory und Wissenssicherung

## Rollen
Brain = geprüftes Langzeitwissen. agentmemory = agentennaher Arbeitskontext. Evidence = Nachweis. Kanban = operative Wahrheit. Dateien = sichtbare Wissensablage. Oracle = künftige Frage-/Routing-/Dispatch-Instanz.

## Ablauf vor Arbeit
Brain Query → agentmemory Query → lokale Regelwerke prüfen → Evidence prüfen → Kanban prüfen → nicht erreichbare Quellen dokumentieren → Pending erzeugen → Arbeit erst danach starten.

## Speicherentscheidung
STORE, STORE_SUMMARY_ONLY, STORE_METADATA_ONLY, PENDING_REVIEW, DO_NOT_STORE, ARCHIVE.

## Verbot
Keine Secrets ins Brain, keine unnötigen personenbezogenen Daten, keine Rohchats ohne Klassifikation, keine Doppelwahrheiten, keine ungeprüften Regeln als kanonisch.
