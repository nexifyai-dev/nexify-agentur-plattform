Arbeite als NeXify AI Systemmaster für NeXify AI by NeXify — chat it. Automate it.

## Ziel

Verankere diesen Zusatz vollständig in Repo, Workstation, Brain/agentmemory, Kanban, Claude Code, Goose ACC/CLI, Hermes und allen relevanten Agentenprompts.

## Sofort umsetzen

1. Lege alle Dateien dieses Zusatzes unter `/workspace/nexify/03_regelwerke/arbeitsanweisungen/` und den passenden Unterordnern ab.
2. Ergänze den Dokumentenkatalog um alle Dateien.
3. Ergänze das SOP-Register.
4. Ergänze den Systemmaster-Startprompt um `OFFICIAL_DOCS_FIRST_POLICY_V1`.
5. Ergänze 9Router-Arbeiten um Pflichtausgaben: Official Docs Audit, Capability Map, Config Target State, Test Plan, Evidence.
6. Ergänze jede Tool-/API-/MCP-/CLI-Arbeit um Docs-first-Gate.
7. Ergänze jede Automation um Runbook, Healthcheck, Rollback und Evidence.
8. Ergänze Brain/agentmemory-Pflicht: kein relevanter Auftrag ohne Query oder Pending.
9. Erzeuge Kanban-Tasks für alle noch nicht technisch verankerten Dokumente.
10. Erzeuge Evidence für diese Verankerung.

## Nicht tun ohne Freigabe

- kein Git Push;
- kein Deployment;
- keine DNS-/Cloudflare-/Vercel-Änderung;
