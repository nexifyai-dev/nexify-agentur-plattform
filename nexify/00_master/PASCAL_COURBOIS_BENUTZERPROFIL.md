## 11. Brain-, Oracle- und Memory-Erwartung

Pascal erwartet, dass Brain nicht optional ist.

Alle relevanten AI-Lösungen müssen Brain nutzen für: Kontext, Entscheidungen, Lessons Learned, Fehlerhistorie, Systemzustand, Kundenkontext, Architekturentscheidungen, wiederkehrende Probleme, Betriebslogik, Prompt- und Skill-Verbesserungen.

## 17. Security-, Secret- und DSGVO-Erwartung

Pascal erwartet:
- keine Secrets im Klartext
- keine Token in Logs
- keine Private Keys in Chat/Brain/Repo
- Secret-Refs statt Rohwerten
- Rotation bei Exposition
- DSGVO-konforme Trennung
- Access Policies für interne Oberflächen
- Cloudflare Access für Workspace, Router, Traefik und Adminbereiche
- Audit- und Evidence-Pflicht

Hochgeladene oder sichtbar gewordene Schlüssel sind als kompromittiert zu behandeln und zu rotieren.

---

## 18. GitHub-, Repo- und Deployment-Erwartung

Pascal erwartet, dass GitHub vollständig als operative Steuerung genutzt wird:
- Issues, PRs, Projects, Labels
- Rulesets, Branch Protection
- Actions, CodeQL, Dependabot
- Secret Scanning, Webhooks, GitHub App
- Auto-Merge nur nach Gates

Repo und Deployment müssen gemeinsam geprüft werden. Code ohne Live-/Vercel-/Cloudflare-Prüfung ist nicht ausreichend, wenn die Aufgabe produktionsrelevant ist.

---

## 19. Cloudflare, Vercel, DNS, Tunnel und externe Erreichbarkeit

Pascal erwartet klare Trennung:
- Website-Domains über Vercel
- interne Apps über Cloudflare Tunnel
- Access/Auth für interne Oberflächen
- keine ungeschützten Admin-/Traefik-/Router-Endpunkte
- keine DNS-/SPF-/DKIM-Fehlkonfigurationen
- externe Health-Prüfung zusätzlich zu localhost

Ziel:
```
nexifyai.cloud und www → Vercel
brain → Cloudflare Tunnel + Auth/Store-Schutz
ai-router → Cloudflare Tunnel + Auth/Access
work → Cloudflare Tunnel + Auth/Access
traefik → nur geschützt oder entfernt
```
