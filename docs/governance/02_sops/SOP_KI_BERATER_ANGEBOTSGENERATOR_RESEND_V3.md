# SOP — KI-Berater-Chat, Angebotsgenerator und Resend-Mailversand

## Ziel
Der KI-Berater-Chat wird zum qualifizierten Vertriebs- und Angebotskanal.

## Chat-Flow
Begrüßung → Anliegen erfassen → Projektart klassifizieren → Ziel/Kontext erfragen → Ist-Zustand erfassen → Soll-Zustand erfassen → Budget/Zeitrahmen/Dringlichkeit → Risiken/Compliance → passende Leistung auswählen → offene Fragen erkennen → Angebotsentwurf erstellen → Review/Approval → Mail/PDF erzeugen → Versand nach Gate.

## Angebotsdaten
Kunde/Lead, Ansprechpartner, Projektziel, Ausgangslage, gewünschtes Ergebnis, Leistungsbausteine, Optionen, Annahmen, Risiken, Nicht-Leistungen, Preis, Laufzeit, Support, nächster Schritt, Gültigkeit, Datenschutz-/AVV-Hinweis.

## Versand-Gate
Versand nur, wenn Empfänger bestätigt oder rechtlich geprüft, Angebot vollständig, Preis/Marge geprüft, keine falschen Zusagen, Mailtemplate geprüft, Resend-Konfiguration funktionsfähig und Evidence erzeugt ist.
