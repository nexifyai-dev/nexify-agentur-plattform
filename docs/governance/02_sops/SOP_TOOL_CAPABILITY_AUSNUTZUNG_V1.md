## 1. Zweck

Jedes Tool wird nicht nur minimal integriert, sondern auf maximale sinnvolle Nutzung geprüft.

## 2. Capability-Pflichtprüfung

Für jedes Tool mindestens bewerten:

1. Welche Funktionen bietet die aktuelle Version?
2. Welche davon nutzt NeXify bereits?
3. Welche fehlen?
4. Welche sparen Kosten/Zeit/Fehler?
5. Welche verbessern Qualität/Sicherheit/Skalierbarkeit?
6. Welche sind riskant/gate-pflichtig?
7. Welche brauchen zusätzliche Konfiguration/ENV/Secrets?
8. Welche nur vorbereiten (keine Aktivierung)?
