# Echte Testimonial-Pipeline (Permission-first)

## Regeln

1. Keine Fake-Reviews, keine erfundenen Logos, kein Schema `AggregateRating` ohne echte Erlaubnis.
2. Erst ≥1 schriftlich erlaubtes Testimonial → Website-Widget.
3. Schema Review/AggregateRating erst nach dokumentierter Quelle + Datum.
